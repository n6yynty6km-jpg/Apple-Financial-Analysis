Apple Financial Analysis

Учебный проект по анализу финансовых данных Apple за 2009–2024 годы.

Использованные инструменты

Python
Pandas
Matplotlib
SQL
SQLite
Google Colab

#Что было сделано

В проекте я:

загрузила и проверила исходные данные;
проверила наличие пропусков и дубликатов;
посмотрела основные финансовые показатели;
рассчитала рост выручки и чистой прибыли;
рассчитала чистую маржу, EBITDA Margin и Operating Margin;
посмотрела соотношение долгосрочного долга и активов;
построила несколько графиков;
выполнила SQL-запросы для анализа данных.

#Основные результаты

Период анализа: 2009–2024
Максимальная выручка — **394 328 млн** в 2022 году.
Максимальная чистая прибыль — **99 803 млн** в 2022 году.
Максимальный рост выручки — **65.96%** в 2011 году.
Максимальный рост чистой прибыли — **84.99%** в 2011 году.
Максимальная чистая маржа — **26.67%** в 2012 году.
